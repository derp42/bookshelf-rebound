# Code of Conduct

Bookshelf Rebound is a collaborative technical project. Be respectful, constructive, and specific. Disagreement about code and compatibility is welcome; harassment, personal attacks, discrimination, threats, and disclosure of another person's private information are not.

Project spaces include issues, pull requests, discussions, reviews, and other channels explicitly used for project work. Maintainers may edit, hide, or remove contributions that violate these expectations and may temporarily or permanently restrict participation when necessary.

Report conduct concerns privately to the initial maintainer through the contact options on the [`derp42` GitHub profile](https://github.com/derp42). Reports will be handled as confidentially as practical. Maintainers involved in a report must recuse themselves from deciding its outcome when another maintainer is available.
