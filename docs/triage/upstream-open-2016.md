# Upstream open-issue triage: 2016

This register covers every open `bookshelf/bookshelf` issue created from
2016-01-01 through 2016-12-31 inclusive. The inventory was queried on
2026-09-03 with:

```text
repo:bookshelf/bookshelf is:issue is:open created:2016-01-01..2016-12-31
```

Rebound disposition status is current through 2026-09-08.

The GitHub Search API returned 69 issues and this register contains exactly 69
issue rows. Pull requests were excluded by `is:issue`. The review used issue
bodies and comments, linked issues and pull requests, inherited Git history,
the current Rebound source and tests at `002ab8f`, and the installed Knex
2.5.1 behavior. Targeted read-only SQLite-memory or SQL-compilation probes were
used where they could settle current behavior. Age alone was never treated as
evidence that an issue was fixed.

## Decision vocabulary

- **P0**: security exposure or likely data loss.
- **P1**: confirmed correctness, isolation, or common-path failure.
- **P2**: compatibility or worthwhile backward-compatible capability.
- **P3**: documentation, diagnostics, or support ergonomics.
- **P4**: stale, breaking, application-specific, or outside the maintained 2.x scope.
- **FIX**: correct an existing Rebound defect.
- **ADD**: accept a backward-compatible capability or documentation addition.
- **VERIFY**: reproduce on the relevant supported matrix before choosing a change.
- **ALREADY_FIXED**: current Rebound or its supported Knex baseline supplies the behavior.
- **DUPLICATE**: track under the cited canonical issue.
- **REJECT**: do not add the request to the maintained 2.x core; use the recorded alternative.
