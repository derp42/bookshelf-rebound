# Security Policy

## Supported versions

Bookshelf Rebound is currently in release-candidate status. Security fixes are provided for the latest `2.x` release line.

The original `bookshelf` npm package is maintained by a different project and is not covered by this policy.

## Reporting a vulnerability

Please use GitHub's **Security** tab and choose **Report a vulnerability** to send a private report. Do not open a public issue for an undisclosed vulnerability.

Include the affected version, database dialect, a minimal reproduction, potential impact, and any known mitigations. We will acknowledge the report as promptly as practical and coordinate disclosure after a fix or mitigation is available.
